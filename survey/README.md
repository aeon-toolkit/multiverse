# Moved to `published_results/`

This directory was renamed to
[`published_results/`](https://github.com/aeon-toolkit/multiverse/tree/main/published_results),
which describes what it holds: accuracies reported in the multivariate time series
classification literature, one file per surveyed paper.

Nothing was removed. Every file moved with its history intact, so a link to a specific
file still resolves after swapping `survey` for `published_results` in the path:

    survey/Convolutional/Fauvel2021XCM.csv
    published_results/Convolutional/Fauvel2021XCM.csv

This file exists only so links to the old directory still land somewhere useful. GitHub
does not redirect directory URLs.
