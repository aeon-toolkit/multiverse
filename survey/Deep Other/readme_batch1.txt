Batch 1 extracted classification tables

Files included
- Gao2024FDNet.csv: Table 1 classification results on 23 UEA datasets from FDNet.
- Gao2025DAPNet.csv: Table 1 results from DAPNet. Includes 10 UEA datasets and 2 CICIDS datasets because the main table mixes both.
- Gu2024RTNet.csv: Table 1 classification results on 15 UEA datasets from RTNet/TSNet.
- Huang2024MTSFNet.csv: Table I classification results on 10 UEA datasets from MTSFNet.
- Jeong2024DECM.csv: Table V performance on the UEA archive from ODE-RGRU/DECM paper.
- Kim2023FEAT.csv: Table 1 multivariate classification results on 30 UEA datasets from FEAT.
- Li2021ShapeNet.csv: Table 1 UEA archive results from ShapeNet.

Notes
- Franceschi2019USRL.pdf does not contain the per-dataset UEA results table in the uploaded main paper. The paper states that full multivariate UEA scores are in the supplementary material (Section S4, Table S5), but that supplementary table is not present in the uploaded file, so no CSV was produced for this paper.
- For papers where the printed table used abbreviations, dataset names were expanded to standard UEA names in the CSVs.
- Missing entries in the papers were kept as blank/NaN in the CSVs.
- Jeong2024DECM.csv required image-based extraction from the table page, followed by manual cleanup, because text extraction did not preserve the table structure.
